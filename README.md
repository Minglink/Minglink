## Profile

- **主要方向：** DeepSeek Harness 社区生态、AI 辅助逆向工程、可视化工作流与本地知识库。
- **项目技术：** JavaScript / TypeScript / Python，结合桌面端、移动端与本地工具链开发。
- **关注点：** 工具之间的协作、可复用的任务流程，以及从分析到交付的完整体验。
- **项目理念：** 分享工具、工作流与实践记录，让更多人能上手使用、反馈问题、参与改进。

## Current Focus

- **无限系列与逆向工具：** 围绕无限五代，把静态分析、原生调试、仿真和协议研究接入 AI 工作流。
- **DeepSeek Harness 社区生态：** 维护桌面社区版、工作流插件与配套工作流包，完善安装与使用体验。
- **知识与智能体：** 通过万象知识库沉淀会话和项目经验，探索本地检索、知识图谱与移动端 Agent。
